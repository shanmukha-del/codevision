Event Format & Stages

A fast-paced, multi-stage frontend challenge focused on real-world engineering excellence.

Stage 1: Architecture & Wireframe

Analyze the problem track released at 10:00 AM. Structure pure semantic HTML5 elements and define scalable CSS variables.

Stage 2: Responsive Engineering

Build adaptive layouts utilizing CSS Grid, Flexbox, and fluid typography. Zero frontend libraries or JavaScript frameworks permitted.

Stage 3: Jury Evaluation & Awards

Live presentation before our expert faculty jury. Evaluated on UI fidelity, CSS architecture, responsiveness, and performance.

Academic Standards

Rules & Regulations

Strict compliance is mandatory to maintain academic integrity.

01

Pure HTML5 & CSS3 Only

Solutions must be constructed using vanilla HTML5 and CSS3. CSS frameworks (Bootstrap, Tailwind) and JS UI libraries are prohibited.

02

Team Structure (1–2 Members)

Teams may consist of an individual developer or a duo. Cross-department and cross-institution collaborations are welcome.

03

Originality & Clean Code

All code written must be original and developed on-site during the 5-hour duration. Pre-existing full codebases are disqualified.

04

Identity & Pass Mandate

Every participant must present their original College ID card alongside the printed CODEVISION Team Pass at the entry gate.
